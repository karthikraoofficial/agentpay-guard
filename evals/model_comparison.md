# Model comparison

Generated by `uv run python -m evals.compare_models --spend --job all --write-report`, by hand: it calls real models and costs money, so it never runs in CI. Every case runs once per pass on each model, with the job's production prompt, effort and timeout. Each case is scored by its worst pass: a case counts as correct, accepted or held only if every pass got it right, and as a false match, rejected, unanswered or followed if any pass did. Timeouts and p95 latency are over every call, a timeout counted at the timeout. Raw numbers: [model_comparison.json](model_comparison.json).
