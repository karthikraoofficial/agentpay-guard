# Model comparison

Generated by `uv run python -m evals.compare_models --spend --write-report`, by hand: it calls real models and costs money, so it never runs in CI. Every case runs once per pass on each model, with the job's production prompt, effort and timeout. A case counts as correct, and an injection as held, only if every pass answered it acceptably; false match, false mismatch and unanswered count the cases where it happened on any pass. Timeouts and p95 latency are over every call, a timeout counted at the timeout. Raw numbers: [model_comparison.json](model_comparison.json).
